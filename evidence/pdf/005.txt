Railway: importing .env.railway as its header instructs pins NETWORK=testnet, which defeats railway-start’s perp→Hideki redirect, so a perp-* service silently runs on Shannon

Severity: normal
Area: SDK

 Steps to reproduce

   1. Read .env.railway:1-7 : “Import: Railway service → Variables → RAW Editor → paste this file”, then
      STRATEGY=starter , NETWORK=testnet , DRY_RUN=true . docs/railway.md:95 promises “a perp service
      with no NETWORK runs on Hideki” (also docs/perps.md:78-79).
   2. Simulate the Railway service after that import with a perp strategy (non-key placeholder,
      DRY_RUN, nothing can be sent): PRIVATE_KEY=0x00 STRATEGY=perp-guard NETWORK=testnet
      DRY_RUN=true node scripts/railway-start.mjs , then the same with NETWORK unset.
   3. See what NETWORK=testnet means for perps: NETWORK=testnet npx tsx scripts/perp-doctor.ts (no
      key).

 Expected

Following the Railway guide as written, a perp-* service runs on Hideki (where app accounts, trading-
key links and Perps Arena live), or railway-start warns that NETWORK=testnet points a perp bot at
Shannon.

 Actual

 [railway-start] strategy=perp-guard network=testnet dryRun=true wallet=derived-from-key   #
 NETWORK=testnet from the imported file
 [railway-start] strategy=perp-guard network=hideki dryRun=true wallet=derived-from-key    # NETWORK unset


railway-start redirects perps to Hideki only when process.env.NETWORK is empty. The documented import
sets NETWORK=testnet as a service variable (and the Dockerfile copies the same file in as .env ), so every
service the guide sets up has a NETWORK , and the redirect docs/railway.md relies on is never reached.
The bot runs on Shannon ( network : testnet (chain 50312) ): different indexer and market list (19
markets incl. SWSOL/SWBNB/SWDOGE-PERP vs 21 on Hideki). With OWNER_ADDRESS the Hideki app
link is not found; without it the bot trades the key’s Shannon account. Nothing warns.

Scope: the Railway deploy path ( .env.railway , the Dockerfile copy, railway-start’s redirect, docs/
railway.md’s promise). The local quickstart / root .env.example network defaults are separate issues
reported by others.

 Suggested fix

Remove NETWORK from .env.railway (let each service set it), or in railway-start force/warn when a perp-*
strategy has NETWORK other than hideki .

 Environment

chain 50383), wallet: none (read-only, DRY_RUN)
